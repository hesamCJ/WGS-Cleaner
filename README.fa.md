### ⚠️ اطلاعیه نسخه بتا

Cleaner Pro در حال حاضر در **نسخه بتا عمومی** است.  
قابلیت‌های اصلی کار می‌کنند، اما باگ، حالت‌های خاص و ناقص بودن جزئیات ظاهری محتمل است.  
ابتدا روی سیستم غیراصلی یا ماشین مجازی تست کنید.  
قبل از پاک‌سازی‌های سنگین حتماً **نقطه بازیابی سیستم (System Restore Point)** بسازید.

---

## ✨ قابلیت‌ها

| ماژول | توضیح |
|--------|--------|
| **داشبورد** | نمودار زنده CPU و RAM، فضای دیسک، آپ‌تایم، تعداد برنامه‌ها و استارتاپ |
| **برنامه‌های نصب‌شده** | آیکون واقعی، جستجو و مرتب‌سازی، Uninstall و **Force Remove** با اسکن باقی‌مانده‌ها |
| **آنالیز دیسک** | بزرگ‌ترین پوشه‌ها و فایل‌ها در هر درایو + حذف امن |
| **یابنده فایل تکراری** | بر اساس SHA-256 (عکس / ویدیو / سند / همه) |
| **پاک‌کننده موقت** | Temp، Prefetch، کش آپدیت، Thumbnail، Crash Dump، سطل آشغال، DNS و … |
| **پاک‌کننده مرورگر** | Chrome · Edge · Firefox · Opera · Brave |
| **مدیریت استارتاپ** | فعال / غیرفعال / حذف ورودی‌های راه‌اندازی |
| **مدیریت پردازه‌ها** | لیست زنده، End / Force Kill، باز کردن مسیر |
| **سرویس‌های ویندوز** | Start · Stop · Restart · تغییر نوع شروع |
| **پاک‌کننده رجیستری** | تشخیص مسیرهای خراب + Restore Point قبل از تغییر |
| **بهینه‌سازی یک‌کلیکه** | پاک‌سازی ترکیبی با گزارش خلاصه |
| **سلامت SSD / HDD** | وضعیت SMART، مدل، سریال، فریمور |
| **اطلاعات سیستم** | سیستم‌عامل، CPU، RAM، درایوها، شبکه |
| **تنظیمات** | تم تیره / روشن / سیستم، اجرا با ویندوز |

### 🛡️ اولویت با امنیت

- قبل از هر عمل مخرب، تأیید از کاربر  
- در حد امکان ارسال به سطل آشغال (Recycle Bin)  
- ساخت نقطه بازیابی قبل از Force Remove و پاک‌سازی رجیستری  
- هیچ حذف بی‌صدای فایل‌های کاربر یا پوشه‌های سیستمی ویندوز وجود ندارد

## 🚀 راه‌اندازی سریع

```bash
git clone https://github.com/YOUR_USERNAME/CleanerPro.git
cd CleanerPro
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
ساخت فایل EXE تکی
Bashpython build.py
خروجی: dist/CleanerPro.exe (بدون کنسول).

📁 ساختار پروژه
textCleanerPro/
├── main.py
├── core/          # پوسته برنامه، تم، لاگ
├── services/      # اسکنرها، پاک‌کننده‌ها، مانیتور
├── pages/         # تمام صفحات رابط کاربری
├── widgets/       # کامپوننت‌های قابل استفاده مجدد
├── utils/         # مسیرها، بارگذاری آیکون و …
├── assets/icons/  # آیکون برنامه
├── reports/       # گزارش‌های HTML / PDF
└── build.py

⚠️ سلب مسئولیت
این نرم‌افزار می‌تواند رجیستری را تغییر دهد، فایل حذف کند و سرویس‌ها را کنترل کند.
مسئولیت تأییدها با خود شماست.
سازنده مسئول از دست رفتن داده یا مشکل سیستم نیست.
فقط در صورت نیاز با دسترسی Administrator اجرا کنید. ترجیحاً روی VM یا سیستم فرعی تست کنید.
